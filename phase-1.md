### Resumen Rápido
- **Estado:** COMPLETA
- **Flujo:** Bienvenida → Selección de Mono / Tortuga / Tucán → Hogar de la Mascota → Navegación reversible.
- **Gráficos:** Ilustraciones y paisajes SVG originales vectoriales en paleta tropical cálida.
- **Interacciones:** Pointer Events nativos para tocar (tap) y acariciar (swipe) con feedback visual inmediato (estrellas y corazones flotantes).
- **Controles táctiles:** Botones principales ≥ 64px, accesibles para niños de 3 a 5 años sin texto denso ni emojis como iconos.
- **Ajustes:** Modal propio para adultos (sonido y confirmación de reinicio sin `window.confirm`/`alert`).
- **Verificación:** `npm.cmd run build` (código 0) y `npm.cmd run lint` (código 0).
